This version of Firmalife requires at least TFC v4.1.0.

### Changes
- Added the ability to smoke items on pineapple strings.
- Fixed automation capabilities of drying mats not working for solar driers.
- Fixed not being able to smoke cheese.
- Fix barrel presses crashing the game.
- Added pineapple yarn to the common strings tag.
- Fixed firmalife metals not rendering as ingots.
- Allow using carne asada as a meat item in meal recipes.
- Fix stone countertops being uncraftable.
- Fix missing barrel recipe localization.
- Fix a bug where items could be given cellar traits outside a cellar.
- Removed recipes associated with pumpkin chunks jam.
- Updated Chinese translation.
